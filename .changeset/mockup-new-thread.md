Mockup threads now start from **New thread** in the Mockup panel's header. It opens an empty thread over the page's copy, with the message box, **+ Add comment**, and selecting an element of the copy to ask about it. The list no longer has a message box, and elements of the copy are chosen only in a new thread. The thread is saved with its first message, so going back before sending one saves nothing; what was typed or added waits for the next new thread until Mockup mode is left.
