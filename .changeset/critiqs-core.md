Add `critiqs`, Critiqs for any web app: a script tag that adds Critiqs from `data-project-id`, `<critiqs-app>` for server-rendered pages, and `mountCritiqs()` for framework packages, with `setContext()` to report the current view and `routeContext()` and `routePath()` for routers. `<Critiqs />` in `critiqs-react` now uses the same mounting code, with no change in behavior.
