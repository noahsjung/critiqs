Tickets can now go to GitHub Issues as well as Linear. On Convex, each person connects GitHub in **Your trackers** with a fine-grained personal access token, or, where the operator sets `CRITIQS_GITHUB_CLIENT_ID`, `CRITIQS_GITHUB_CLIENT_SECRET`, and `CRITIQS_GITHUB_APP_SLUG` for their GitHub App (callback `/trackers/github/callback`), by signing in through the app; a sign-in is saved only when one of the GitHub account's verified emails is the person's Critiqs email. Create ticket offers the repositories that take issues, puts the thread's link in the issue's text (GitHub can't take the capture as an image), and finds an issue whose answer was lost instead of creating another; Link ticket searches by address, `owner/repo#12`, or words, and adds the thread's link as one comment. Owners can offer repositories' issue templates and issue forms, and labels are suggested from tags. Status comes back from signed `issues` webhooks at `POST /trackers/github/webhook` (`CRITIQS_GITHUB_WEBHOOK_SECRET`) and from the check when a thread opens, with **Resolve when done**. A delivery counts only as of the issue's own update time, at most a day old, and each repository's deliveries may change linked tickets 300 times a minute (429 past that). The webhook secret signs deliveries about any repository, so a deployment several teams share keeps it in the operator's app and never gives it to a team. A comment or link back goes to the issue by its node ID, never by its repository's name and number, which a rename or transfer changes and another repository may take; deliveries and the check follow an issue whose repository was renamed or that was transferred as the same node, issue forms' labels and one-line answers stay literal text (a `render` field becomes a code block), and disconnecting a GitHub sign-in deletes the app's grant for the person at GitHub, refreshing an expired access token first, since GitHub needs a valid one; a retry is skipped once the person has connected GitHub again, since deleting the grant would end the new sign-in too. `/critiqs/config` reports GitHub among `tickets.trackers`, with `installUrl` where the app is set up. A tracker sign-in now checks every verified email the tracker reports. The self-hosted SQLite server is unchanged.
