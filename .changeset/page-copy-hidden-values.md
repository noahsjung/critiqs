Page copies for mockups leave out values the page never shows, which only its scripts read (no script runs in a copy). Left out: the value of each hidden form field (`type="hidden"`, or a field with the `hidden` attribute that isn't displayed); HTML comments; the content of every `<meta>` tag except `viewport`, `color-scheme`, `supported-color-schemes`, `referrer` and `format-detection`, such as anti-forgery tokens, keys and descriptions; Inertia's `data-page`, Phoenix LiveView's `data-phx-session` and `data-phx-static`, Livewire's `wire:snapshot`, `wire:effects` and `wire:initial-data`, Turbo's `signed-stream-name` and Astro islands' `props`; and any other `data-*` or `prefix:name` attribute whose name contains `csrf` or `xsrf`, or whose value is JSON or a single token of 100 characters or more, unless the page's CSS names that attribute. Those tags and attributes stay, empty, so the copy looks the same. Still copied: text and visible form values, shorter `data-*` values, other attributes (such as a form's `action` address or a button's `value`), fields hidden only by CSS, and the addresses of the page's images and stylesheets. Copies made by earlier versions keep what they held.
