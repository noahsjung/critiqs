A Connected report from the project's address written with a final dot (`https://acme-proto.vercel.app.`) is kept as the address itself. Both backends drop a report that can't count before reading anything; on Convex such a report no longer runs a mutation. An address saved before its project moved to another organization no longer counts for Connected, as it already didn't for the extension's lookup.
