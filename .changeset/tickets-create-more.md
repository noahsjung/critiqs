Two more ways to create tickets. The new-comment box offers **Also create a ticket** where threads can create tickets: once the comment is saved, its thread opens with Create ticket (or Your trackers, with none connected). The comments list's selection offers **Create tickets…** beside Export…: one ticket per selected thread, filled from the thread as Create ticket fills it, at the destination Create ticket would start with, skipping threads that already have a ticket, up to 20 at a time. It shows each thread's progress, names the threads left without a ticket and why, pauses at the per-person limit of tickets a minute and continues on its own a minute later while the dialog stays open, saying when, and **Try again** retries only those under their first submissions. Both use the existing ticket functions; no backend change.
