Reshape the Mockup panel around threads. The toolbar button and panel now say **Mockup**, and the panel has two levels: one list of every page's mockup threads, this page's first, each labeled with its page, view state, first message, author, and latest version, most recently active first, showing 20 of this page's threads and 20 of the other pages' at first, each with **Show more**; then the thread itself, where each Critiqs AI reply carries its version to view or restore, **Hold to compare** (or holding **O**) shows the live page, and width tabs appear when the thread has several copies. Each thread is its own proposal: asking for a change, below the list or on an element of the copy, starts a new mockup named after the message, with its own copies and versions. Opening a thread from another page asks to go there first and calls the host's `restoreContext` with its screen and view state; without it, or when the page can't be shown, the thread opens on its saved copy and says comparing with the live page isn't available. Restoring a version shows in the thread with its version card, so the latest version is always marked. **+ Add comment**, beside either message box, links up to 20 of the project's comments for Critiqs AI to read, shown as removable chips. The mockup list, title field, version menu, and **Original** button are gone. Signed out, the Mockup button now shows and, like **M**, asks to sign in, as Comment mode does.

Deploy the matching Critiqs backend first: the panel reads the new `mockups:listPage`, one screen's mockups with threads or every other screen's a page at a time, and every message in a mockup thread now moves its mockup up the list; mockups record when they were listed (`listedAt`), so run `npx convex run mockups:backfillListedAt` once on a deployment that already has mockup threads; `mockups:list` now returns each mockup's threads and, given a screen, all of that screen's mockups; `mockups:create` links the comments added for it in the same step; and a mockup refuses a second thread. `critiqs_mockups` lists each mockup's threads with their first messages.
