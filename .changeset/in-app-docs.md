The Project panel has a **Documentation** section. **Open documentation** shows what each part of Critiqs does and how to use it: the toolbar and modes, the Project panel, commenting, threads, the comments list, search, tags, export, links and notifications, Mockup mode, Critiqs AI, project setup, coding agents, and keyboard shortcuts. A search box narrows it, and **Back** returns to the panel it came from.
