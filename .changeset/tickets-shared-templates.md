Ticket templates now include the ones teams share. Linear's workspace templates, which belong to no team, are listed in Tags and AI → Tickets as **Workspace templates (every team)**; one an owner turns on is offered in every team and creates the issue from it. A GitHub repository without its own `.github/ISSUE_TEMPLATE` folder uses its owner's public `.github` repository's templates, as GitHub does, and the Tickets tab says where they come from. A saved choice for every team uses the destination ID `*` (`EVERY_DESTINATION`); template groups may carry `from`. Deploy the matching backend.
