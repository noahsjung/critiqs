Add **Your trackers…** to the avatar menu, beside **Your AI…**, on backends that report `tickets` in `/critiqs/config`. Each person connects their own Linear account, through Linear's sign-in in a window served by the backend or with a pasted Linear API key, chooses whether their new tickets say they came from Critiqs (on by default), and can disconnect it; disconnecting a Linear sign-in also revokes its tokens at Linear (a pasted API key stays valid until its person deletes it in Linear). The Convex backend reports `tickets` once its operator sets `CRITIQS_AI_ENCRYPTION_KEY`, which now also encrypts tracker tokens; Linear sign-in needs `CRITIQS_LINEAR_CLIENT_ID` and `CRITIQS_LINEAR_CLIENT_SECRET`. The self-hosted SQLite server doesn't offer tickets. Disconnecting tells the person what still works at the tracker: a pasted key, or a sign-in Linear couldn't be told to end (Critiqs then tries again for about an hour). A Linear token counts as ended only once Linear no longer accepts it, since Linear answers a revocation it couldn't make as it does one already made. Disconnecting also cancels a sign-in still under way, so its window connects nothing. Creating and linking tickets come in a later release.
